# Injam Vamshi Reddy — Portfolio

Personal portfolio built with React, TypeScript, Vite, and styled-components.

## Run locally

1. Install Node.js and npm.
2. Open this folder in a terminal.
3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL printed in the terminal.

## Personalize before publishing

- Verify the LinkedIn URL in `src/components/Hero/Hero.tsx` and `src/components/Footer/Footer.tsx`.
- Replace the GitHub profile links in `src/components/Project/Project.tsx` with the specific repositories for each project when available.
- Add a profile photo if desired.
- Confirm the resume PDF in `public/Injam_Vamshi_Reddy_Resume_.pdf` is the latest version.
- Review the contact details before making the site public.
